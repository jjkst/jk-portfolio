Why the Markdown step is the whole point

rule

Every rule is cited

A rule points at the artifact it came from — Spec.pdf p.14, a source file, a sheet. Anything the pipeline had to guess is tagged (inferred) so you know exactly what you are vouching for.

compare_arrows

Conflicts surface early

When the documents say 5 attempts and the code says 3, that row goes in a conflict table and waits for a named human. It is not silently resolved, and it is not turned into a test.

edit_note

You edit the file, not a prompt

Download it, change it, re-upload it. Test cases are generated from your reviewed copy, so corrections land once and flow through to every scenario and feature file.
